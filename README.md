# 🤖 AI Smart Calculator App

An advanced and intelligent **AI-powered Smart Calculator App** built for Android.
This app combines a traditional calculator with **AI solving capabilities and OCR (image scanning)** to solve math problems instantly.

## ✨ Features

* 🧮 **Basic & Scientific Calculator** — Perform daily and advanced calculations
* 🤖 **AI Problem Solver** — Solve math expressions with intelligent responses
* 📸 **OCR Scan & Solve** — Capture math problems from images and solve instantly
* ⚡ **Fast & Lightweight** — Smooth performance with optimized code
* 🎨 **Modern UI** — Clean and user-friendly interface
* 🔄 **Real-time Results** — Instant calculation output

## 🧠 Core Functionalities

### 🧮 Calculator Mode

* Addition, Subtraction
* Multiplication, Division
* Clear & Reset functions

### 🤖 AI Mode

* Solve complex math queries
* Smart responses using AI logic

### 📸 OCR Mode

* Scan handwritten or printed math problems
* Extract text using ML Kit
* Automatically solve detected equations

## 🛠 Tech Stack

* **Android Studio** — Development environment
* **Java** — Core programming language
* **XML** — UI design
* **ML Kit (OCR)** — Text recognition
* **AI Model (Llama / API)** — Smart solving system
* **Material Design** — Modern UI components
